# Bring Them Home — Replica

A self-contained front-end replica inspired by the referenced Bring Them Home rescue game.

## Run
Open `index.html` directly in a browser.

## Deploy to Vercel
1. Create a new Vercel project.
2. Upload this folder or connect the repository.
3. Framework preset: Other / Static.
4. Build command: none.
5. Output directory: `.`

## Included
- Responsive landing page
- Callsign/deployment flow
- Operation selection
- Mission briefing
- Playable rescue mini-game
- Countdown extraction timer
- Keyboard + touch controls
- Civilian rescue tracking
- Tactical map
- Pause/restart flow
- Training
- Operator profile
- Loadout lobby
- Leaderboard
- Season pass
- Store
- Settings
- Mission completion screen

The implementation uses original CSS/HTML/JS and does not require a backend or external packages.
